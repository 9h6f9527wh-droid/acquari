# Acquari

Gioco web per iPad: un acquario-ecosistema con una parte gestionale.

- Il piano di sviluppo, fase per fase, è in [PIANO.md](PIANO.md).
- Per provarlo sul computer serve un piccolo server locale (i moduli JavaScript non funzionano aprendo il file con doppio clic):
  `python3 -m http.server` nella cartella del progetto, poi apri http://localhost:8000
